# Children Prop Notes

## 1. What is the children prop?

`children` is a special React prop containing the content placed between a component's opening and closing tags.

## 2. Why is children useful?

It makes reusable layout components flexible because the layout does not need to know exactly which content it will contain.

## 3. What is passed inside PageLayout?

Header, main content containing EmployeeDirectory, and Footer are passed inside PageLayout.

## 4. How does this demonstrate composition?

PageLayout combines several smaller reusable components into a complete page structure. This is component composition.
